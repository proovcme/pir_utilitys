# Программа тестирования

## Цель

Проверить, что калькулятор корректно считает стоимость проекта, сохраняет данные, позволяет пользователю управлять составом работ и выгружает Excel с формулами.

## Уровни тестирования

1. Unit-тесты доменной логики.
2. Тесты Excel-экспорта.
3. UI smoke-тесты.
4. Ручная приемка UX.
5. Desktop smoke-тесты Tauri.
6. Регрессионная проверка перед релизом.

## Команды

```bash
npm run build
npm test
npm run tauri build
```

## Unit-тесты расчета

Файл:

```text
tests/calculation.test.ts
```

### CALC-001. Golden baseline

Проверить default seed:

- активных строк: 15;
- себестоимость: `3 970 541,64`;
- буфер: `119 116,25`;
- итого без НДС: `4 089 657,89`;
- НДС: `899 724,74`;
- итого с НДС: `4 989 382,62`.

Критерий приемки: все значения совпадают до округления, заданного в тесте.

### CALC-002. Ручное включение строки

Действия:

1. Найти строку вне активных пресетов.
2. Поставить `manualInclude = true`.
3. Пересчитать.

Ожидание:

- активных строк стало на 1 больше;
- строка есть в `activeLines`.

### CALC-003. Исключение строки

Действия:

1. Взять активную строку.
2. Поставить `excluded = true`.
3. Пересчитать.

Ожидание:

- строка исчезла из `activeLines`.

### CALC-004. Ручная сумма

Действия:

1. Создать строку типа `Ручная сумма` или `Ручной`.
2. Поставить `manualAmount = 123456`.
3. Пересчитать.

Ожидание:

- себестоимость равна `123456`.

### CALC-005. Нет ставки

Действия:

1. Активной ФОТ-строке поставить несуществующую группу.
2. Пересчитать.

Ожидание:

- `warningCount = 1`;
- warning содержит `Нет ставки`.

### CALC-006. Подрядная строка

Действия:

1. Любой раздел перевести в тип `Подряд`.
2. Ввести договорную сумму.
3. Пересчитать и выгрузить Excel.

Ожидание:

- стоимость строки равна введённой сумме;
- предупреждение об отсутствии ставки не возникает;
- формула листа `Конструктор` учитывает тип `Подряд` как ручную сумму.

### CALC-007. Состав ПП №87 и общие работы

Проверить:

- для ОКС присутствуют разделы 1–13 в актуальной нумерации;
- ООС находится в разделе 8, ТХ — в разделе 6;
- доступны акустика, обследование, лазерное сканирование и геодезия.

## Тесты Excel-экспорта

Файл:

```text
tests/excelExport.test.ts
```

### XLSX-001. Валидный workbook

Ожидание:

- файл создается;
- размер больше 1000 байт;
- листы существуют: `Итог`, `Оценка`, `Конструктор`, `Справочники`, `Пульт`.

### XLSX-002. Ключевые формулы

Проверить:

- `Пульт!B23 = B21+B22`;
- `Пульт!B28` содержит `SUMPRODUCT` для человекодней;
- `Итог!B5` ссылается на человекодни;
- `Итог!E4` содержит `SUMIFS`;
- `Итог!J4 = IFERROR(I4/E4,0)`;
- `Конструктор!R2` содержит формулу активности;
- `Конструктор!W2` содержит `VLOOKUP`;
- `Конструктор!AA2` содержит формулу стоимости;
- `Оценка!A9` ссылается на `Конструктор!AG`;
- `Оценка!N9` ссылается на `Конструктор!AA`.

### XLSX-003. Массовая проверка формул

Ожидание:

- `Итог` содержит больше 20 формул;
- `Оценка` содержит формулы по активным строкам;
- `Конструктор` содержит формулы по расчетным колонкам;
- `Пульт` содержит больше 10 формул;
- в текстах формул нет `#REF!`, `#VALUE!`, `#DIV/0!`, `#NAME?`, `#N/A`.

### XLSX-004. Ручная проверка в Excel/LibreOffice

Действия:

1. Выгрузить Excel из приложения.
2. Открыть файл.
3. Изменить ставку в `Справочники`.
4. Изменить срок/состав в `Конструктор`.
5. Пересчитать книгу.

Ожидание:

- `Конструктор` меняет стоимость строки;
- `Оценка` подтягивает изменение;
- `Итог` меняет totals;
- нет ошибок формул.

## UI smoke-тесты

Пока не автоматизированы Playwright-тестами; выполнять вручную после крупных UI-изменений.

### UI-001. Итог

Проверить:

- верхние карточки видны;
- есть `Человекодни`;
- нет ставок и шага роли;
- нет массовых значений строк;
- разбивка по группам содержит `% прибыли` и строку `Итого`.

### UI-002. Расчет

Проверить:

- есть кнопки `Ручная строка`, `В раздел 5`, `Из базы РД`;
- массовые значения строк находятся здесь;
- строки сгруппированы по стадиям;
- в заголовке стадии можно менять `Дн.`;
- в строке можно менять индивидуальные дни;
- ручной ввод находится в колонке `Стоимость`;
- комментарий раскрывается кнопкой `+`;
- неактивные строки не засоряют расчет нулевыми ценами.

### UI-003. Добавление строки

Действия:

1. Нажать `Ручная строка`.
2. Убедиться, что строка появилась и активна.
3. Сменить тип на `ФОТ`, группу, состав, дни.
4. Убедиться, что стоимость изменилась.

### UI-004. Добавление в Раздел 5

Действия:

1. Нажать `В раздел 5`.
2. Убедиться, что строка появилась под Разделом 5.
3. Изменить подраздел, наименование, группу, состав.
4. Убедиться, что сумма Раздела 5 обновилась.

### UI-005. База РД

Действия:

1. Нажать `Из базы РД`.
2. Найти марку через поиск.
3. Отметить несколько строк.
4. Нажать `Добавить выбранные`.

Ожидание:

- строки появились в расчете;
- поиск не остался забит ID добавленной строки;
- стоимость считается.

### UI-006. Конфигурация наборов

Проверить:

- в таблице нет пользовательского столбца `ID`;
- можно выбрать строки галочками;
- можно создать набор;
- можно добавить выбранные строки в существующий набор;
- кнопки `Применить` в конфигурации нет.

### UI-007. Ставки

Проверить:

- экран показывает группы, а не сырой технический список;
- можно менять описание группы;
- можно менять медиану ведущего;
- инженер и главспец пересчитываются по шагу роли;
- множитель ставок находится здесь;
- шаг роли находится здесь;
- CSV/XLSX экспорт/импорт работает.

### UI-008. Визуальный стиль

Проверить:

- sidebar Mexican Red `#a72525`;
- table headers Mexican Red;
- бренд в sidebar выглядит как заголовок, а не кнопка;
- текст не обрезается в основных колонках;
- наименование строки читаемо;
- чекбоксы и focus-state в красной гамме.

## Desktop smoke-тесты

Платформы:

- macOS.
- Windows.
- Linux.

Минимум для каждой платформы:

1. Приложение запускается без консоли.
2. Открывается главное окно.
3. Можно изменить параметр проекта.
4. Можно сохранить шаблон.
5. Можно выгрузить Excel.
6. Excel-файл открывается в Excel/LibreOffice.
7. Локальные данные переживают перезапуск.

## Регрессионный чеклист перед релизом

- `npm run build` зеленый.
- `npm test` зеленый.
- Нет синего цвета в основных UI/Excel-заголовках.
- Новый расчет не показывает неактивные строки с нулями.
- Раздел 5 можно пополнять явно.
- Ручная строка добавляется явно.
- Ставки редактируются как группы.
- Excel содержит формулы.
- Desktop bundle собирается.
