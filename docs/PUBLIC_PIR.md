# Публичный расчёт стоимости проектных работ

## Граница редакций

Полная сборка `npm run build` предназначена для защищенного маршрута Locia `/calculator`. Она содержит коммерческую оценку, ставки, ПП №87, подряд, шаблоны, историю, Excel и синхронизацию портфеля.

Публичная сборка `npm run build:public-pir` предназначена только для `https://les.ovc.me/pircalc/`. Ее отдельная точка входа формирует связанный комплект сметных документов: сводную форму 1П, нормативную форму 2П по данным ФГИС ЦС и калькуляции по трудозатратам 3П согласно Методике № 707/пр. В 3П используются официальные индексы квалификации из таблиц 1.3 и 1.4, фиксированные `Кз = 0,4` и `Р = 10%`; исходные данные о зарплате и рабочих днях вводятся вместе с источником. Состояние сохраняется только в браузере пользователя. Сборка не вызывает API и не содержит внутренних ставок или коммерческих модулей.

`scripts/check_public_pir_bundle.mjs` завершает сборку ошибкой, если в JavaScript появляются маркеры защищенных функций или если HTML теряет базовый путь `/pircalc/`.

## Публикация

Статические релизы хранятся на VPS в `/var/www/pircalc/releases/<UTC release id>`. Caddy обслуживает symlink `/var/www/pircalc/current`; переключение релиза выполняется атомарно. Маршрут имеет собственный `handle_path` до общего fallback сайта LES.

Для HTML действует `Cache-Control: no-store`. Политика CSP запрещает сетевые подключения, формы, фреймы и внешние скрипты. Исходный каталог ФГИС включается в bundle, поэтому расчет работает без браузерных запросов к ФГИС ЦС.

## Минимальный gate

```bash
npm test
npm run build
npm run build:public-pir
```

После публикации проверяются `/pircalc` → `/pircalc/`, HTML и ассеты, security headers, отсутствие приватных маркеров в живом JavaScript, переключение форм 1П/2П/3П, контрольный нормативный расчёт и контрольная калькуляция 3П.
