# Снимок ПИР из ФГИС ЦС

## Назначение

Калькулятор не обращается к ФГИС ЦС из браузера: публичные API портала не отдают CORS-заголовки, а нормативный расчет должен открываться и без сети. Вместо этого репозиторий хранит версионированный нормализованный снимок, а официальные файлы — в отдельном локальном аудиторском архиве.

Источники:

- раздел ФГИС ЦС: `https://fgiscs.minstroyrf.ru/frsn/pir/methods`;
- сообщение Главгосэкспертизы от 03.08.2026: `https://gge.ru/press-center/news/vse-piry-vo-fgis-tss/`;
- публичный API: `https://fgiscs.minstroyrf.ru/api`.

Все сетевые запросы выполняются через SSH-хост `zt-box`.

## Файлы

- `src/data/fgisPirSnapshot.json` — контракт для приложения: периоды, категории, документы, индексы и источник;
- `src/data/fgisPirManifest.json` — контрольный манифест скачанных файлов;
- `outputs/fgis-pir/2-q-2026/raw-api.json` — необработанные ответы API;
- `outputs/fgis-pir/2-q-2026/documents/` — локальные копии официальных PDF/XLSX;
- `scripts/sync_fgis_pir.py` — воспроизводимая синхронизация.

Каталог и манифест версионируются. Документы из `outputs/` не попадают в Git и в защищенный пакет Locia.

## Обновление

```bash
npm run fgis:sync
```

Для проверки только метаданных без скачивания документов:

```bash
python3 scripts/sync_fgis_pir.py --ssh-host zt-box --metadata-only
```

После обновления обязательны:

```bash
npm test
npm run build
```

## Расчетный контракт

Калькулятор автоматически выбирает данные, однозначно опубликованные ФГИС для документа и периода:

- название и GUID норматива;
- базисный уровень цен;
- индекс перехода к выбранному кварталу;
- реквизиты утверждения;
- официальный URL документа.

Для документов, включенных в `src/data/fgisPirTables.json`, дополнительно выбираются:

- таблица и объект проектирования;
- название и единица натурального показателя;
- границы интервала;
- параметры `a` и `b` в тысячах рублей;
- страница официального PDF и SHA-256 исходного файла.

Сметчик выбирает таблицу и объект, затем вводит один понятный физический показатель. Строка диапазона и параметры `a`, `b` подставляются из официальной таблицы и показываются до результата. Вне опубликованного диапазона `a` и `b` обнуляются: калькулятор не выполняет скрытую интерполяцию или экстраполяцию.

Для еще не структурированных проектных документов остается явно помеченный ручной режим. Инженерные изыскания не считаются формулой проектных работ: их будущий расчет должен суммировать выбранный состав работ по показателям затрат ПЗ.

Проверяемая цепочка для структурированной строки:

```text
Cбаз = a + b × X
или
Cбаз = Cстр × p

Cусл = Cбаз × Kусл × Kдоп
Cтек = Cусл × I
Cндс = Cтек × (1 + ставка НДС)
T = Tбаз × Kсрок
```

Расшифровка:

- `a` — фиксированная часть базовой цены из строки таблицы;
- `b` — цена одной единицы натурального показателя в базовом уровне цен;
- `X` — физический параметр объекта из задания на проектирование или утвержденных ТЭП;
- `Cстр` — стоимость строительства для процентного метода;
- `p` — нормативная доля проектирования;
- `Kусл` — коэффициент условий или сложности;
- `Kдоп` — дополнительный коэффициент с отдельным нормативным основанием;
- `I` — индекс перехода из базового уровня цен документа в выбранный квартал ФГИС;
- `Tбаз` и `Kсрок` — исходная нормативная продолжительность и коэффициент срока.

В структурированном каталоге натуральный показатель раскрывается по смыслу строки:

| Единица / объект | Что вводится |
| --- | --- |
| `кв. м` | общая площадь выбранного объекта |
| `куб. м` | строительный объем здания |
| `м`, горнолыжная трасса | протяженность трассы |
| `м`, канатная дорога | протяженность линии канатной дороги |
| `га` | площадь территории открытого объекта |
| `зрителей` | вместимость трибун |
| `шт.`, стрелковый объект | количество огневых позиций |
| `посадочное место` | проектная вместимость объекта общественного питания |

Значение `X` всегда проверяется по диапазону выбранной строки. Если сумма долей ПД и РД превышает 100%, калькулятор нормализует их пропорционально; если она меньше 100%, остаток остается в категории прочих работ. Excel использует тот же алгоритм и содержит отдельную колонку с расшифровкой каждого параметра и шага.

Выбор норматива, таблицы, объекта, диапазона и паспорт ФГИС сохраняются в проекте, шаблоне, истории и на отдельном листе `СБЦ ФГИС` Excel-выгрузки.

Каталог таблиц пересобирается из локального аудиторского архива:

```bash
npm run fgis:tables
```

Генератор `scripts/extract_fgis_pir_tables.py` требует `uv` и ставит `pdfplumber` во временную среду команды. Сгенерированный JSON проверяется тестами; PDF в веб-сборку не включаются.
