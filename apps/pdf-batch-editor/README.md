# Редактор содержания ПД 0.0.1

Tauri-приложение в первую очередь для пакетной корректировки содержания PDF проектной документации: текстов, надписей, таблиц, изображений, логотипов и штампов. Операции со страницами являются вспомогательным инструментом.

## Возможности 0.0.1

- области в миллиметрах с привязкой к листу, основной надписи СПДС, фактическому верху штампа или левому нижнему углу;
- выбор страниц, ориентации и типа документа ТЧ/ГЧ;
- точный поиск, регулярное выражение по словам, фамилия рядом с датой, вставка без поиска;
- замена, добавление и удаление текста;
- гарнитура или произвольный TTF/OTF, кегль, минимальный кегль, автоподбор, цвет, фон, выравнивание, поворот, полужирный и курсив;
- JSON-профили правил, JSON-отчёт и PNG-превью;
- автономный PDF-sidecar: пользователю не нужен Python.
- загрузка одного PDF или пакета PDF с продолжением очереди после ошибки отдельного файла;
- анализ структуры комплекта, титульных листов, форматов и штампов;
- распознавание ролевых строк штампа: Разработал, Проверил, ГИП, ГАП, Н. контр. и других;
- точечная и пакетная замена полей штампа без удаления линий таблицы;
- замена любого текста с сохранением исходных шрифта, кегля и цвета;
- замена текстовых и графических логотипов;
- последовательные операции со страницами: удалить, оставить выбранные, повернуть, дублировать, извлечь в отдельный PDF и вставить страницы из другого PDF;
- совместное использование операций над страницами и содержимым в одном задании;
- скрытый запуск PDF-движка без консольного окна.

Главный режим интерфейса — `Содержание`. `Штамп` является готовым отраслевым профилем, а `Страницы` — дополнительным сервисным разделом. Встроенные правила по умолчанию выключены: пользователь явно выбирает каждое изменение перед запуском.

Основные пользовательские сценарии:

- выбрать папку проекта: приложение рекурсивно найдёт PDF и выполнит одно задание для всего комплекта;
- заменить человека по роли в штампе (`ГИП`, `ГАП`, `Разработал`, `Проверил`, `Н. контр.`), не зная заранее старую фамилию;
- заменить организацию в основной надписи, в том числе без ввода старого названия для стандартного штампа;
- открыть лист в прямом редакторе, нажать на текстовый блок и добавить точечную замену или удаление с сохранением исходного оформления;
- обнулить заполненные значения распознанных штампов без удаления рамки, сетки и служебных подписей, затем выгрузить выбранные листы в отдельный PDF.

## Архитектура анализа

Редактор разделяет чтение и изменение документа:

1. анализатор строит карту файлов, страниц, текстовых блоков, штампов и таблиц;
2. интерфейс превращает выбор пользователя в независимый список операций;
3. PyMuPDF-движок применяет операции к копии PDF;
4. отчёт и превью позволяют проверить результат.

Проект [`proovcme/les-list`](https://github.com/proovcme/les-list) рассматривается как внешний read-only анализатор. Его `drawing_manifest`, карта томов, positioned text blocks, реестр таблиц и `source_ref` могут подключаться через адаптер к общей карте документа. Сам редактор не должен зависеть от внутренних схем Л.И.С.Т.: на границе используется собственный стабильный контракт, поэтому анализатор можно обновлять или заменять независимо от движка правок.

Встроенный профиль `profiles/spds_stamp_mvp.json` рассчитан на формы 3-6 СПДС. Для фамилий используется внутренняя область ячейки с зазором до линий таблицы; если текст не помещается даже на минимальном кегле, движок выдаёт предупреждение.

## Разработка

```powershell
pnpm install
python -m pip install -r requirements.txt
pnpm build:sidecar
pnpm tauri dev
```

## Сборка Windows

```powershell
pnpm build:desktop
```

Готовый NSIS-установщик создаётся в `src-tauri/target/release/bundle/nsis/`.

## Ограничения 0.0.1

- для поиска и замены нужен текстовый слой PDF;
- OCR сканов и визуальный редактор области мышью запланированы на следующие версии;
- неподписанный Windows-инсталлятор может показать предупреждение SmartScreen.

## Лицензирование PDF-движка

Приложение использует PyMuPDF. PyMuPDF распространяется по GNU AGPL либо по коммерческой лицензии Artifex. Перед распространением закрытых бинарных сборок необходимо получить коммерческую лицензию или обеспечить соответствие всего продукта требованиям AGPL.
